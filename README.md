# Portafolio Web - Karen Barroso

## Descripción

Este proyecto consiste en el desarrollo de un portafolio web personal realizado como proyecto final del curso de Desarrollo Web de Coderhouse. El sitio fue desarrollado utilizando HTML5, SCSS, Bootstrap 5 y animaciones con AOS, aplicando buenas prácticas de desarrollo, diseño responsivo, optimización SEO y organización del código mediante arquitectura de partials en SCSS.

## Tecnologías utilizadas

* HTML5
* SCSS
* CSS3
* Bootstrap 5
* AOS (Animate On Scroll)
* Git
* GitHub
* Vercel
