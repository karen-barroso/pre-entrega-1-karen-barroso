# Portafolio Web - Karen Barroso

## Descripción

Este proyecto consiste en el desarrollo de un portafolio web personal realizado como proyecto final del curso de Desarrollo Web de Coderhouse.

El sitio fue desarrollado utilizando HTML5, SCSS, Bootstrap 5 y animaciones con AOS, aplicando buenas prácticas de desarrollo web, diseño responsive, optimización SEO y organización del código mediante una arquitectura de partials en SCSS.

## Tecnologías utilizadas

* HTML5
* CSS3
* SCSS
* Bootstrap 5
* AOS (Animate On Scroll)
* Git
* GitHub
* Vercel

## Características del proyecto

* Sitio web estático compuesto por 5 páginas.
* Diseño adaptable a dispositivos móviles, tablets y escritorio.
* Navbar responsive con menú hamburguesa utilizando Bootstrap.
* Estilos desarrollados con SCSS mediante variables, mixins, nesting, extend y partials.
* Animaciones con SCSS y librería externa AOS.
* Optimización SEO mediante etiquetas title, meta description, meta keywords y atributos alt en imágenes.
