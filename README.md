# Portafolio Web - Karen Barroso

## Descripción

Este proyecto consiste en el desarrollo de un portafolio web personal creado para presentar mi perfil profesional, mis servicios y proyectos relacionados con el desarrollo web. Fue realizado como parte de la pre-entrega del curso de Desarrollo Web de Coderhouse utilizando HTML5, CSS3 y Bootstrap 5, aplicando diseño responsive para una correcta visualización en diferentes dispositivos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Git
- GitHub
